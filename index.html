⚡ Watch Face Format (WFF) Exporter & Sideload Guide

This is the official Watch Face Format (WFF) v2.0 declarative XML for Google Wear OS 5 & 6 (Samsung Galaxy Watch 8 / 7 / Ultra). It dynamically reflects all your configured colors, complications, and activity metrics.

1. Enable Wireless Debugging on Galaxy Watch 8

On your Galaxy Watch 8, navigate to Settings > About watch > Software info and tap Software version 7 times. Then go to Settings > Developer options and enable ADB debugging and Wireless debugging.

2. Pair with Your Computer via ADB

Tap Pair new device on the watch to get the pairing port and 6-digit code. Run in terminal:

adb pair <WATCH_IP>:<PAIRING_PORT> <CODE>

Then connect using the main wireless debugging port:

adb connect <WATCH_IP>:<PORT>

3. Build & Install

Download the pre-configured Android Studio project ZIP below, open it in Android Studio, and click Run or execute:

./gradlew installDebug

The watch face will immediately appear in your Galaxy Wearable app and watch face selector!

Using Samsung Watch Face Studio (WFS)

Samsung Watch Face Studio is Samsung's official visual authoring software for Galaxy Watches.

  • Install Watch Face Studio from developer.samsung.com.
  • Create a new project targeting 450 x 450 (Round display).
  • Add a Digital Clock component with high-weight geometric typeface.
  • Add three Progress Bar (Arc) components mapped to Samsung Health tag expressions: [CALORIES], [ACTIVE_MINUTES], and [STEP_COUNT].
  • Add Complication Slots for Heart Rate and Battery.
  • Export directly as a signed APK or upload to the Google Play Console!
